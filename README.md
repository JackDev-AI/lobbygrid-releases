# LobbyGrid downloads

Windows installers for LobbyGrid, the 12-pane Xbox Cloud Gaming lobby console.

**Download:** see [Releases](../../releases/latest) → `LobbyGrid-Setup-<version>.exe`.

- Windows 10 / 11, 64-bit.
- A LobbyGrid licence key is required. Keys come from your seller.
- The installer isn't code-signed yet: on "Windows protected your PC", choose **More info → Run anyway**.

This repository only hosts installers. It contains no source code.
